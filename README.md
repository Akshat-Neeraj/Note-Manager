## 📋 Overview

Note Manager is a web-based application designed to help users organize their notes and tasks in a simple, efficient way. Built as a learning project to explore full-stack web development with Node.js, Express, and EJS templating.

**Project Goals:**
- Learn full-stack web development fundamentals
- Build a practical CRUD application
- Explore server-side rendering with EJS
- Implement RESTful API design patterns

## ✨ Features

### Current Features
- 📝 **Create Notes** - Add new notes with title and content
- ✏️ **Edit Notes** - Update existing notes easily
- 🗑️ **Delete Notes** - Remove notes you no longer need
- 📋 **View All Notes** - See all your notes in one place
- 🎨 **Clean UI** - Simple, intuitive interface
- 💾 **Persistent Storage** - Notes are saved and persist across sessions

## 📦 Installation

### Prerequisites
- Node.js (v14 or higher)
- npm (comes with Node.js)

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Akshat-Neeraj/Note-Manager.git
   cd Note-Manager
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the server**
   ```bash
   npm start
   ```

4. **Open in browser**
   ```
   Navigate to: http://localhost:3000
   ```

## 🚀 Usage

### Creating a Note
1. Click the "New Note" button
2. Enter a title and content
3. Click "Save"

### Editing a Note
1. Click on any note to view it
2. Click the "Edit" button
3. Make your changes
4. Click "Save"

### Deleting a Note
1. Click on the note you want to delete
2. Click the "Delete" button
3. Confirm deletion
